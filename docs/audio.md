# DSSC, starvation synth and RAVE

Primary record: [Hackteria sonic-device experiments](https://www.hackteria.org/wiki/A_RAVE_and_starvation_synth_based_generative_sonic_device_powered_by_dye_sensitized_solar_cell), with pp. 66–75 of the booklet. Upstream: [Starvation Synth by Ralf Schreiber](https://wiki.sgmk-ssam.ch/wiki/Starvation_Synth_by_Ralf_Schreiber), [RAVE](https://github.com/acids-ircam/RAVE), [IRCAM nn~](https://forum.ircam.fr/projects/detail/nn/).

1. Use the published starvation-synth circuit as the starting point. Log component values (including R1–R3 / C1–C3), supply source, actual supply voltage, routing and measured output. Use an appropriately buffered/attenuated signal to the audio interface; confirm level and DC offset before connecting. Document baseline with stable illumination before varying shadows or light.
2. In a supported audio host, route the captured signal to a dry track and in parallel to RAVE (`nn~` with a compatible model, or the documented Neutone host route). Match sample rate, buffer and recording gain. Record exact host, plug-in build, model name/file hash and model license. Start by loading the host's stock model through its supported UI; export dry and wet examples from the same capture. Archive your patch and model identifier for reproducibility, rather than relying on an account or proprietary plug-in preset.
3. Compare raw vs processed recordings at comparable levels. The residency examples distinguish DSSC photophone/laser input, starvation-circuit output with a silicon solar source, and LED photophone demonstration without RAVE. Report which is being reproduced; source hardware, host versions and trained weights were not all published. Use a diffuse LED or existing recorded input for software bring-up; the documented 405 nm installation is a separate optical experiment requiring a suitable enclosed/interlocked setup.
4. Record light source, distance/modulation, circuit values, input level, gain/latency, raw WAV and processed WAV for each condition. Media can be contributed with clear reuse permissions. For the optical canon, follow the author's [source reference](https://github.com/shihweichieh2023/Canon_a_2_per_Tonos_in_galvos); audio-model weights and recordings are not part of this release.
